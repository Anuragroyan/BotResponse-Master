🤖 Python Rule-Based Chatbot
Python Rule-Based Chatbot is a simple conversational application built with Python that responds to user messages using predefined rules and responses. Instead of relying on machine learning or external AI services, it uses keyword matching and conditional logic to understand common user inputs and provide appropriate responses.

✨ Features
* 🤖 Rule-based conversation
* 💬 Interactive text-based chat
* 🔤 Keyword-based input detection
* 🧠 Predefined conversational rules
* 🔀 Conditional response handling
* 👋 Greeting and basic conversation support
* ❓ Handles unknown or unsupported inputs
* 🚪 Exit/quit command handling
* ⚡ Lightweight and fast
* 🌐 No backend or external AI API required

🛠️ Tech Stack
* Python – Application development
* Conditional Logic – Rule evaluation
* String Processing – Input analysis
* Keyword Matching – Intent identification
* Terminal / CLI – User interaction

🎯 Project Purpose
This project demonstrates the fundamentals of building a chatbot without machine learning or generative AI. It provides practical experience with Python functions, loops, conditions, string processing, user input handling, and rule-based conversational logic.
